# Art brief — KO blast (WK-22, feeds WK-23)

Date 2026-11-14 · Author: art pipeline (art-director brief) · Backlog WK-22 [P1][S] · Source: audit D-01

## What & why
D-01 (P0): ring-outs happen off-camera by construction (the camera never shows past the kill bounds), so
the KO — the punchline of the core loop — is shake + hitstop + a sound with nothing to see. WK-23 adds a
Smash-style **screen-edge KO blast in the victim's colour**: on `KillPipeline.killed` the death point is
projected onto the nearest viewport edge and a big burst fires from there, pointing back into the screen.
This brief orders the art for it.

## Deliverable — a small set of TINTABLE layers (not baked colour)
Code animates the layers (scale-pop, fan-out, fade) instead of flipping a ChatGPT frame strip — separate
layers stay style-consistent and let code control timing (<= 0.6 s per WK-23).

## Tintability contract (load-bearing)
- Art is **white / light-grey value art + the house dark-chocolate `#3B241B` outline**, no hue anywhere.
- Body fill ~`#E6E6E6`–`#F2F2F2`, shading down to ~`#BDBDBD`, pure-white gloss highlights.
- Code tints to the victim's colour (`Player` display colour, WK-08). Two acceptable methods:
  1. `modulate = victim_colour` — multiply: fill becomes the colour, outline stays chocolate (dark × colour
     ≈ dark). Gloss flattens a little (white × colour = colour).
  2. **Preferred:** a tiny gradient-map CanvasItem shader on luminance: dark (<0.3) → keep as outline,
     mid → victim colour, top highlights (>0.93) → blend toward white. Keeps the toybox gloss.
- Never generate in a colour; a pink burst can't become a blue goat's burst cleanly.

## Size / readability
- Gameplay camera zoom ~0.46, but the layers live on a **CanvasLayer (screen space)**, so size in SCREEN px
  at 1920x1080: core ~260–340 px, column ~300 px wide × ~420 px deep (stays inside the outer 20 % band —
  "never in the middle 60 %"), ring up to ~420 px, star ~90–120 px.
- Source PNGs should be >= 2x those sizes (generations are ~1024 px — fine; code scales down).
- Bold silhouette, few fat shapes, thick outline: must read at a glance in a 4-player scramble and from a
  640x360 downscale. No thin wisps, no fine sparkle noise, no soft glow haze (glow halos turn into grey
  smudges when tinted).

## Style prompt (base suffix applies)
"Glossy Toybox": thick clean dark-chocolate outlines, soft plastic-toy shine, bold chunky cartoon game VFX.
Every prompt: "Entirely WHITE and light-grey (greyscale only, no colour at all) so the game can tint it
any colour", "no text, no letters", plus the transparent-background clause. Style ref:
`assets/reference/style_north_star.png` (its white jump-streaks are the VFX family) — attached once.
