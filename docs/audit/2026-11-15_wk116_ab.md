## 3. Why the over-fix median clause is noise here

- **No causal path.** The rule is inert before 27 s: M1 found 0 pressure events before t1 − warn in 1303 ON match rallies. A rally the
  rule shortens has already passed 30 s and still ends after 30 s, well above the ~10 s median. So the rule **cannot move the
  median**. It can only move the tail.
- **The arms are not paired.** Same seeds do not give the same matches.
  - Only **9 of 341** P1 rallies are bit-identical to the P0 rally at the same seed and stage.
  - Only **5 of 311** P1s rallies match P1, even though P1 and P1s run identical code until 40 s.
  - Cause: run-to-run nondeterminism, same family as the WK-161 lesson. Each arm is effectively an independent 300-rally sample.
- **Measured noise floor:**

  | Comparison | Median shift | Note |
  |---|---|---|
  | P0 seeds 1-10 vs P0 seeds 11-20 | −0.15 s | same arm, different seeds |
  | **P1 vs P1s** | **−0.92 s** | identical below 40 s; only 4-5 rallies per arm reach 40 s |
  | P1 vs P0 | −0.60 s | 90 % CI [−1.77, +0.66] |
  | P1s vs P0 | −1.52 s | 90 % CI [−2.30, −0.17] |
  | P1t35 vs P0 | −0.07 s | |

  - The P1s shift sits in the 25th percentile and the median alike (6.16 → 5.68 s, 10.45 → 8.93 s). Those rallies end long before
    the rule can act.
  - The pre-registered P1 test agrees: KS on rallies under 27 s is not significant in any arm (p = 0.73 P1, 0.16 P1s, 0.21 P1t35).
- **The clause's other half is the real tail-rule test, and it holds.** Rallies reaching step 1: P1 7.0 %, P1s 6.1 % (bar 15 %).
- **Recommendation for future A/Bs:** give the median clause a noise band (for example, the bootstrap CI of the median must exclude
  ±0.5 s), or test it only on rallies under t1 − warn.
